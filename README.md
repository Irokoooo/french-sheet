# French Sheet v1

Tablet-first static web app that turns fixed-format French reading text into a magazine-style annotation sheet.

## Input

```text
【主题】：科技前沿
【标题】：Titre français
【正文】：Texte français...
```

## v1 scope

- Parse topic / title / body
- Five low-saturation magazine themes
- Adjustable font size, line spacing and margins
- Tablet/mobile responsive layout
- Export high-resolution PNG
- Print / Save as PDF
- Local browser persistence
- PWA shell

No accounts, backend, AI integration, or cloud history in v1. The goal is deliberately narrow: paste text, make a sheet, start studying.

## Deploy

This is a static site and can be deployed as-is to Vercel or GitHub Pages.
